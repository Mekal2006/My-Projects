# Timetable Maker

A lightning-fast, client-side web application designed to streamline university course registration and schedule management. Built entirely with HTML, CSS, and Vanilla JavaScript, this tool requires zero backend setup and runs natively offline in any web browser.

## Core Features

* **Smart Text Parsing Engine:** Built for rapid input. The engine instantly converts lazy inputs like `2pm`, `1130`, or `830a` into perfectly formatted chronological timeblocks.
* **Intelligent Clash Detection:** Automatically audits selected time slots and actively blocks overlapping courses on the exact same day.
* **Automated Time Mathematics:** Automatically calculates end times based on course credit hours, tracks exact gap durations between classes, and tallies total time spent on campus.
* **Color-Coded Visual Grid:** Generates a highly readable, color-coordinated schedule with dynamic brackets, anchored borders, and strict table layouts.
* **State Memory & Quick Edit:** Saves form inputs in a local background dictionary. Click the edit (✎) icon to instantly reload and modify a course without re-typing data.
* **Keyboard-First Navigation:** Optimized for speed during high-stress registration windows. Map through form fields and submit courses entirely using the `Enter` key.
* **Double-Lecture Automation:** Selecting the same day twice seamlessly merges the course into a single extended timeblock.

## Setup & Execution

This application requires no servers, environments, or installations.

1. Clone or download this repository to your local machine.
2. Double-click the `timetable.html` file to launch it in your default web browser.
3. Use the left-hand sidebar to begin adding courses.
